# Madinah.com redesign (static site)

Plain HTML/CSS/JS, no build step. Open `index.html` or host the folder as-is.

- `index.html` is the homepage; every other page is a `.html` file next to it.
- `dc-lite.js` makes the interactive parts work (quick donate, checkout, zakat calculator, merch bag, portals).
- `assets/` holds the logo and merch product images.
- All charities, people, figures and sign-ins are fictional demo content.

Demo sign-ins: `signin-donor.html`, `signin-client.html`, `signin-creator.html`.
